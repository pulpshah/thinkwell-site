# Thinkwell site, v2

The new Thinkwell website, built from the Thinkwell Site boards (`board/site` on the `design/board` branch of
PulpInternet/loosethreads-fr) with the real kit from loosethreads-fr main (8e181df). One page, in this order: the
first screen, How it works, Interactive documents, State and federal policy, Practice, What it learns, Plans, About and
the footer. Light or dark follows the viewer's system; the footer switch changes it. Sample data is marked Sample;
prices and photographs are slots.

To update: rebuild `kit/site.js` and `kit/site.css` from `board/site` (`node build.mjs`, see its README), copy them
here with the marks, and push.
